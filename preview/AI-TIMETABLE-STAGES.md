# AI 操作课表：阶段与验收

## 阶段边界

1. 网页添加 / 删除：用户已确认「基本没有问题开始实现第二阶段」。
2. 网页调课 / 课程替换 / 组合操作：已实现并验证；用户于 2026-09-26 明确授权复测后移植。
3. Android 侧以 ai 变体（`app/src/ai`）接入同一套已验证的 AI 模块，通过原生桥接访问真实课表。保留原仓库其他页面，包名 `com.seu.timetable.ai`，与原版隔离安装。构建与验证说明见 [README](../README.md) 的 AI 章节。

ai 变体包含自然语言课表操作、上下文压缩和图片确认导入；`-PaiUi=compose` 时界面走原生 Compose 浮窗，默认走 WebView 浮窗，两者功能一致。

## 第一阶段行为

- 聊天窗口顶部「普通聊天 / 课表操作」切换。两者分别保存记录和草稿；不同课表的操作对话也分别保存。生成中可停止，不允许同时切换模式触发第二个操作。
- 创建需要课程名、星期、起止节次与周次。根据用户明确选择，未指定周次时必须先追问，不自行默认全学期或当前周；老师、学分、备注可留空，创建后再追问补充。
- 「星期六的12节」按第1–2节理解；明确「第12节」是单节。成功回执显示应用实际写入的名称、星期、节次、周次和地点。
- 可删除整门课及全部时段，也可只删指定周次/星期/节次。多个同名候选时先追问，不默认选第一门；不存在则不改数据。
- 第一阶段只补充当前对话中新建课程的老师、学分、备注或教室；第二阶段已扩展调课、替换，详见下文。
- 默认按预览左侧日期理解「今天 / 明天 / 本周」，窗口中同时显示该日期与当前查看周。两者可以不同，测试相对日期前请检查左侧日期。
- 冲突课程可按用户指令添加，并在结果中列出冲突；同名且时间重叠的重复添加会阻止。
- 最近一次成功操作可撤销。课表之后有修改时，旧撤销入口失效，避免覆盖新改动。关闭浏览器后，数据和可用撤销记录仍保留。
- 课表数据与操作回执一次性写入 localStorage，保存失败不替换内存数据；请求期间切换课表、编辑数据或其他页面写入会阻止过期操作。停止、解析错误、截断输出均不执行。
- 模型只生成有限的 JSON 操作，不执行脚本或 SQL。JSON 模式遵循 [DeepSeek 官方说明](https://api-docs.deepseek.com/guides/json_mode/)，结构正确仍需经过本地业务校验。
- 意图理解由真实大模型完成，不用关键词表或正则把用户输入映射到操作。模型结合当前课表和多轮对话解释口语、时间与指代；本地精确匹配和数值检查只用于校验已经解释出的操作。成功与否仍以本地实际写入结果为准。

## 手动验收

打开 `http://127.0.0.1:4173`，先配置 API Key，进入「课表 → AI → 课表操作」。可顺序发送：

1. `添加一个课程，时间：星期六的12节课，工科数学分析，在礼东上课` → 先追问周次，不增加课程。
2. `第1到16周，每周都上` → 周六第1–2节出现课程，回执追问可选信息。
3. `老师是张老师，学分3.5，备注是带计算器` → 原课程详情更新，不重复创建。
4. `删除本周六的工科数学分析，只删这一次` → 只移除对应周课次，其他周保留；点击撤销恢复。
5. `删除整门工科数学分析，包括全部周次和时间段` → 课程及其时段删除；刷新后可用的撤销仍能恢复。
6. 切到普通聊天发送删除指令 → 只回复模式切换指引，课表不变。

## 第二阶段行为与验收

- 仍由真实模型理解自然语言和前后文，不用关键词映射。对现有课程的调整使用 `change`，在临时副本中组合删除原课次和插入目标课次，完成所有校验后才一次写入浏览器。
- 单次调课只移除指定周的课次，其他周及其他时间段保留。仅改变时间或地点时，保留课程 ID、老师、学分、备注、颜色、编号。只说新的起始节时保持原时长。
- 换为全新课程时，默认沿用原课次的时间、周次和地点；旧课程的老师、学分、备注、编号和自选颜色不复制到新科目。可随后补充新课信息。换为已有课程时复用其 ID 和元信息，不覆盖目标课程其他课次。
- 用户指定日期时只改那一次；明确每周/整学期时才做对应范围的替换。不明确原课次、目标时间或范围时先追问。即使模型遗漏同名歧义，执行层也会列出候选并追问，不直接改动。
- 上下文提供按学期计算的日期、星期、教学周对照。`target.date` 和 `to.date` 由执行层计算周次并检查一致性，处理周日到下周一等跨周情况；显示第几周与「今天」不是一回事。
- 一句话包含多个要求时用 `batch`（最多10步）：全部成功后统一保存，任何一步失败整组不落盘，最近一组可一起撤销。刷新后仍可撤销；后续手动修改会使旧撤销失效。冲突提示以整组完成后的课表为准。
- JSON 空白响应最多恢复一次，改用指定函数的参数返回 reply/action，避免再次依赖相同的 JSON 正文通道。仅此恢复请求关闭 DeepSeek 思考模式（强制函数调用不支持思考模式）。只接受一个已知函数且参数完整的调用，仍经过同一执行层校验；截断、无效结构、取消均不执行。成功动作不会重新生成。

可直接试说（先确保原课存在，并核对左侧预览日期）：

1. `把今天的英语课调整到本周2 23节`。
2. `明天的英语课改成cpp课`。
3. `刚换成的那门课改到下周一上午头两节，教室换成礼西`。
4. `把本周二的英语改到本周三第5、6节，同时把本周二的体育那一次去掉，后续周保持原样`。
5. `从第2周开始，周四的英语都改到每周二下午第6、7节，周五那次不动`。
