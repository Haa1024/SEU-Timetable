# 上下文压缩与课表图片导入

## Codex 实现调研与取舍

2026-09-26 查阅 OpenAI 官方仓库，固定提交 `25270df2615eb4da5b9d4a9a392226933fb096c5`：

- [本地压缩实现](https://github.com/openai/codex/blob/25270df2615eb4da5b9d4a9a392226933fb096c5/codex-rs/core/src/compact.rs)：生成续接摘要，在预算内保留用户消息，重建上下文，成功后保存压缩检查点。其上下文过长错误路径会削减旧历史再尝试。
- [摘要提示模板](https://github.com/openai/codex/blob/25270df2615eb4da5b9d4a9a392226933fb096c5/codex-rs/prompts/templates/compact/prompt.md)：保留进展、决定、约束、未完成工作及关键数据。
- [远程压缩实现](https://github.com/openai/codex/blob/25270df2615eb4da5b9d4a9a392226933fb096c5/codex-rs/core/src/compact_remote_v2.rs)：依赖 Codex 会话状态、模型提供方、远程请求与历史处理。

当前应用使用 DeepSeek 的聊天接口，没有移植 Rust 会话系统或调用 OpenAI 专用压缩接口，也没有声称与 Codex 实现等价。采用相似的检查点思路自行实现：摘要成功后再推进历史边界，保留最近原文，本机原始聊天不删。与 Codex 的超长削减路径不同，本应用压缩失败会保留旧检查点并停止本次回答，请用户重试，不静默丢掉历史。

## 当前行为

- 两种模式及各张课表分别保存摘要。默认保留最近12轮原文；达到轮数或约24000字符/图片权重预算后，较早内容分块压缩。此预算是保守的长度估计，不是服务商精确 token 计数。
- 摘要块按约18000字符/图片权重分组，超长文本分段，图片仍由视觉模型总结。摘要长度上限8000字符。设置的原文轮数最大30，实际请求同时受长度和消息数上限约束。
- 每次请求携带已有摘要及近期原文；摘要作为背景而非系统指令。压缩明确保留失败、撤销、未完成状态，课表操作始终以实时快照为准。
- 顶部显示压缩进度、次数，并可展开查看摘要。刷新后恢复检查点，清空当前聊天同时清空其摘要。长对话摘要可能遗漏细节，原记录仍可回看。
- 课表模式上传图片后只产生 `import_preview`。先识别，再用带星期表头的重叠竖条独立复核；第二次不提供首次猜测，减少沿用错列结果。图片复核有额外 API 调用和耗时。
- 聊天中逐项列出课程、老师、学分、备注、星期、节次、周次和教室。缺少名称、时间或周次，或存在未解答疑问时禁用确认。可继续用自然语言纠正；没有日期/周次时不自动扩展整学期。
- 待确认清单独立于摘要保存，刷新可恢复。图片文字、模型回复及历史摘要都不能触发最终写入；用户选择方式并确认影响后才提交。
- 追加：保留旧课，跳过相同名字/时间/周次及兼容老师/地点的已有课次，保留原元信息。图片未提供老师/教室不视为要求清空它们。明确冲突的同名课不会偷偷覆盖。
- 覆盖涉及周：按清单周次的并集替换这些周的**全部**课次，保留其他周及未排课；不仅限于图片展示的星期列。确认窗口明示范围。
- 覆盖整表：替换全部课程、全部周次与未排课，确认窗口明确告知。
- 导入支持60门课程，每门20个时段；独立于日常最多10步的组合命令。全部校验后一次写入，任一失败不写入；整次可撤销。不接受过期快照、重复确认或其他页面的并发覆盖。
- Android 侧（ai 变体）复用这些模块，原生桥接完成请求、课表原子保存和刷新。

### 真实 API 复测修复

- 真实 API 复测发现同名课程跨星期的时间段可能被合并遗漏。现在独立识别后比较完整时间段，两份不一致时增加图片差异复核；仍减少课次时列入疑问并禁止直接导入，不机械合并模型猜测。
- 确认清单只呈现已验证字段、疑问和本地计算的课程/时间段数量，避免模型正文与其 JSON 清单的计数矛盾。
- 保留近期轮数设置的 1–30 范围现在与实际行为一致（原内部上限为24）；默认仍是12轮，长文本/图片触发提前压缩。
