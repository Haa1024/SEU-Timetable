# 浏览器开发预览

在项目根目录双击 `start-preview.cmd`，浏览器会打开 http://127.0.0.1:4173 。无需安装 Android SDK 或模拟器；需要 Node.js 20+，本机已具备。首次启动自动安装少量 Markdown 渲染依赖（marked / DOMPurify）。双击 `stop-preview.cmd` 停止后台服务。

也可以在项目根目录执行：

```powershell
.\scripts\start-preview.ps1
# 更换端口 / 只启动服务
.\scripts\start-preview.ps1 -Port 4174 -NoBrowser
.\scripts\stop-preview.ps1 -Port 4174
```

## 预览范围

- 今日课程、进行中/即将开始/无课状态。
- 13 节周课表、翻周、跳周、非本周课程、未排课提示。
- 课程详情：通栏课程色块、教师头像、时间/地点/编号汇总、教学周条、横向配色，以及底部固定「删除 / 编辑」。
- 新增/编辑：横向星期选择、全学期/单双周/前后半学期快捷项、多时间段、按作息实时显示起止时刻、本地颜色/学分/备注，顶部和底部固定保存。
- 保存后返回周课表；删除确认显示该课程的时间段数量，确认后删除整门课及全部时段；取消则不修改。
- 多课表切换、复制、删除、新建、自定义作息、浅色/深色主题。
- 我的、提醒设置、账号与帮助入口；需要原生系统的操作会说明边界。
- AI 双模式：课表页可拖动气泡、浮动聊天窗口；普通聊天支持流式文字和图片问答，课表操作支持自然语言添加、删除、调课、课程替换和组合操作；「我的」提供模型配置。
- 4 种手机尺寸（含按手机截图比例设置的 384 × 854），固定演示日期和时间，浏览器本地保存编辑结果。

界面已参考用户提供的四张手机截图校准图标、间距和比例。截图版本为 1.0.0，仓库为 1.2.0，因此保留当前源码中的日期表头、新手引导入口等变化；课程内容仍使用仓库样例，不复制截图里的账号信息。

默认展示 `2026-09-25 10:00`，让仓库样例出现正在上课的状态。左侧「第 9 周」可查看更完整的课程分布。演示日期不是系统当前时间。

**这是独立的 HTML/CSS/JavaScript 交互预览，不是 Compose 编译产物或 Android 模拟器。** 不会连接学校、不收集账号密码、不发送通知、不安装 APK，也不会写入安卓应用数据。页面实现未覆盖所有原生对话框、新手引导与厂商桌面行为。浏览器字体、测量、动画和系统栏与安卓可能不同，最终效果需真机验证。

## 实时更新的边界

| 修改位置 | 预览行为 |
| --- | --- |
| `preview/public/` 下的 CSS、JS、HTML | 保存后自动刷新浏览器；本地数据与当前页面保留 |
| 安卓 `ui/theme/Theme.kt` | 自动重读浅深色、课程调色板、字号与圆角；只有已映射的样式生效 |
| 安卓 `domain/PeriodTimes.kt` | 自动重读默认作息（已在浏览器另存的自定义作息优先） |
| `app/src/test/resources/ehall_*.json` | 自动重读初始演示数据；已经编辑的课表保留浏览器副本，可重置以重新加载 |
| 安卓 `ui/` 其他 Kotlin 文件 | 刷新并显示布局变化提示；**不会自动把 Compose 转为 HTML** |
| `preview/server.mjs` / `source.mjs` / `llm-proxy.mjs` | 停止并重新启动服务 |

后续修改安卓 UI 时，需要同步 `preview/public/` 的对应页面。`layout-baseline.json` 记录人工核对时的安卓 UI 文件哈希，防止只改 Kotlin 后网页仍显示旧布局而没有提示。完成同步和核对后运行：

```powershell
node preview/record-layout.mjs
```

该命令只记录核对基线，**不会生成页面或验证两端等价**。不要为了隐藏提示而直接运行它。非 UI 业务逻辑也不会自动移植到浏览器；相应功能改动需手动检查预览实现。

## 文件对应关系

- `source.mjs`：读取安卓主题/默认作息与仓库 JSON 样例，检查 UI 源码变化。源码结构无法解析时明确报错，不静默使用伪造数据。
- `public/model.js`：浏览器所需周次、日期、颜色和时段逻辑。
- `public/app.js`：`todayPage` / `timetablePage` / `profilePage` / `detailPage` / `editPage` 等页面与演示交互。
- `public/styles.css`：应用内样式和电脑预览外框。以安卓页面为准维护，不改变 Gradle 构建。
- `public/course-pages.css`：按手机截图及 `CourseEditPage.kt` / `CourseDetailPage.kt` 对齐的课程编辑、详情样式。
- `public/ai-chat.js` / `ai-chat.css`：聊天浮窗、图片附件和模型配置页面。
- `public/ai-core.js` / `ai-storage.js`：上下文组装、窗口边界、SSE 解码、IndexedDB 本机缓存。
- `llm-proxy.mjs`：同源聊天请求转发、流式传输、超时与取消，不记录 API Key；仅课表操作模式附带当前课表上下文。
- `timetable-prompt.mjs` / `public/timetable-ai.js` / `public/timetable-request.js`：结构化操作协议、日期与输入校验、课表增删与原子组合、操作回执及撤销；不执行模型生成的代码。
- `server.mjs`：仅监听 `127.0.0.1`，提供静态页面、只读课表数据、SSE 文件变化通知与聊天转发。不会暴露整个仓库。
- `.runtime/`：本机日志和截图，已被 Git 忽略。

测试：`node --test preview/test/*.test.mjs`。自动刷新约有 250 毫秒防抖时间，再加浏览器重载耗时，不是 Compose Live Edit。

停止预览不会清除演示数据。使用左侧「重置演示数据」恢复仓库样例；同一浏览器不同端口的数据相互独立。

课程编辑默认周次与安卓端一致为 `1-16`，但「全学期」快捷项采用课表的总周数（样例为 18 周）。部分非法周次片段会像 `Course.kt` 一样被忽略，完全没有有效周次时不允许保存。输入颜色前展示自动色槽，但仅在手动点选后固定颜色。

## AI 聊天使用与验收

1. 「我的 → AI 模型设置」填写 API Key。默认使用 DeepSeek 官方地址和 `deepseek-flash`，可切换到自定义 OpenAI 兼容接口，设置模型名、视觉、思考模式、温度、输出长度、上下文轮数和系统提示词。
2. 点击「测试连接」验证当前填写的参数，然后「保存设置」。API Key 默认仅保留在当前浏览器会话；主动勾选「在本机记住」才写入浏览器 localStorage（不是加密保险箱）。服务器不会把 Key 写入文件或日志。
3. 回到「课表」点击 AI 气泡。拖动气泡移动位置；拖动聊天窗口顶栏移动窗口，右下角拖动缩放，也可用加减号或放大/还原按钮。窗口大小和位置保存在本机。
4. 默认窗口约 344 × 492；最小 280 × 300，最大宽为屏幕宽减 24，最大高为 `(屏幕高 - 140) × 0.88`，上下保留系统栏和底部导航区域。气泡、顶栏、缩放手柄支持方向键。
5. Enter 发送，Shift+Enter 换行；生成过程中发送键变为停止键。支持 Markdown、复制、重新生成、失败重试。关闭窗口不会中断回复；刷新页面会中断当前请求并保留已缓存部分。
6. 点击照片按钮、粘贴图片或拖入图片。一条最多 4 张，单张原图不超过 8 MB，普通聊天自动缩至最长边1600像素、课表模式2400像素并转换为 JPEG；GIF 仅取静态帧。图片在点击发送后才上传到所配置的模型接口。包含图片的上下文需要视觉模型。
7. 聊天、图片和未发送草稿自动写入 IndexedDB；刷新可恢复。没有会话目录。清空按钮删除本机聊天与附件，不删除模型配置或课表。浏览器清理网站数据、隐私模式或更换端口会影响缓存。

上下文默认保留最近12轮原文，较早内容自动压缩为摘要；长度较大时会提前压缩。本机完整记录保留，可展开查看摘要。普通聊天和各张课表分别保存摘要，压缩失败不丢弃历史。单个请求最多24 MB，代理最长等待180秒，响应最多8 MB。失败时保留已收到的内容并提供重试。

课表操作中可上传课表照片：模型识别并复核后，在聊天内列出完整待确认清单。先补齐周次/不清楚的信息，可继续自然语言纠正；之后选择追加、覆盖涉及周或整表覆盖，核对影响并确认后才写入。导入可整次撤销。Codex压缩源码调研、功能边界及真实照片验收见 [上下文与图片导入说明](CONTEXT-AND-IMAGE-IMPORT.md)。

**普通聊天不会读取或操作课表。** 切换「课表操作」后，当前课表、作息和预览日期会作为上下文发给所配置的模型；返回内容经过校验后写入浏览器课表。两种模式都不附带校园账号。操作记录按课表分别缓存，普通聊天独立缓存。未说明周次先追问，创建后可补充老师、学分和备注；成功操作不能重新生成，最近一次操作可在没有后续修改时撤销。详见 [分阶段范围及验收](AI-TIMETABLE-STAGES.md)。

Android 侧以 ai 变体接入上述课表操作、自动压缩和图片确认导入。原有 Android 课表页面继续使用 Compose，仅 AI 窗口复用随 APK 打包的网页模块，通过原生接口操作真实课表，不依赖电脑预览服务器。

模型和图片格式依据 [DeepSeek 官方视觉文档](https://api-docs.deepseek.com/guides/vision/) 与 [Chat Completion API](https://api-docs.deepseek.com/api/create-chat-completion/) 实现。2026-09-26 已用用户提供的测试 Key 从网页实际验证连接、流式文字和图片识别；测试图片是绿色方块与“SEU 42”，不包含个人信息。记录见本机 `.runtime/ai-live-result.json`；该目录不提交 Git。
